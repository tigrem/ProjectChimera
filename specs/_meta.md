# Project Chimera – Master Specification (_meta)

## Project Identity
Project Chimera is an autonomous AI influencer system designed to:
- Detect trends
- Generate compliant content
- Publish across platforms
- Operate safely under governance

This is an agentic system, not a single script or app.

## Core Principles
- Specification-Driven Development (SDD)
- Safety before autonomy
- Observability before scale
- Human override is always possible

## Hard Constraints
- Agents MUST read specs before acting
- No code generation without spec alignment
- All outputs must pass safety validation
- All actions must be observable via MCP

## Non-Goals
- No real-money ad optimization (yet)
- No unsupervised posting on Day 1 deployments
- No prompt-only decision making
